# Security Policy

## Supported version

Only the latest public-preview commit is supported. The adapter is not approved
for production or sensitive institutional data.

## Reporting

Do not place secrets, personal data, private review packets, credentials, or
exploit details in a public issue. Use GitHub private vulnerability reporting
when available. Otherwise open a minimal issue requesting a private reporting
route without including the sensitive details.

## Current security posture

The preview has no filesystem, network, shell, credential, model, publication,
or execution capability. Those absences reduce the current surface but do not
establish production safety, dependency safety, host safety, specification
conformance, or institutional fitness.
